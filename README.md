# Data Classification using Machine Learning

## Description
This project demonstrates data classification using Machine Learning algorithms. It predicts the category of data based on training datasets and evaluates model performance.

## Features
- Data preprocessing
- Model training
- Classification prediction
- Accuracy evaluation
- Simple implementation
